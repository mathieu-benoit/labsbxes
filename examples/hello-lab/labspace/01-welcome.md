# Welcome

This Labspace runs **inside a Docker Sandbox**. The instructions you are reading and the VS Code on the right are two processes in the same microVM.

Click **Run** to send a command to the IDE terminal:

```bash
whoami && pwd
```

Save a file into the project with the **Save** button:

```text save-as=hello.txt
Hello from the Labspace kit!
```

Then open it: :fileLink[hello.txt]{path="hello.txt"}
